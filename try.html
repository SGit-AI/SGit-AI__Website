Try sgit in your browser

This page downloads a Python runtime (Pyodide, ~20 MB) and installs the real sgit-ai wheel from PyPI — the same code pip install gives you — then runs it right here. Everything executes in your browser: key derivation, encryption, an in-memory vault. Nothing you type leaves this page.

What this is: the in-memory demonstration of sgit's engine running client-side. The full network transport (clone/push/pull from the browser) is the next milestone — the server's CORS is already verified open for it. First load is heavy (~20 MB, cached by your browser afterwards); key derivation runs 600,000 PBKDF2 rounds in WebAssembly, so expect ~1–2 s where native takes ~0.3 s.

sgit.ai

sgit is git for encrypted vaults — clone, commit, branch and merge files that are encrypted with AES-256-GCM before they leave your machine. Open source, Apache-2.0, in beta and powering production workflows.

🔒 This site is itself served from an encrypted SG/Send vault — the page you are reading was decrypted in your browser. The medium is the message.
