A proposed partnership between sgit.ai and Anthropic

This site is already a Claude Code project, and vaults are how its sessions work together. sgit.ai, its briefs, its deployment docs and most of its thirty-six published vaults are built and published by Claude Code sessions that share state through a vault. We would like to turn that working practice into a partnership: a vault connector in Anthropic's Connectors Directory, skills that teach Claude to use vaults well, and a place in the Claude Partner Network.

Nothing on this page is confidential, and there has been no conversation yet. Every statement about Anthropic comes from its own public pages, linked. Every statement about sgit points at the deployment documentation, a published vault or a page on this site. sgit is Apache-2.0, so Anthropic does not need our permission to run it or to build on it. A partnership is about doing that well and together. The general argument is on the AI providers page.

In short

  • The practice exists. Claude Code sessions build this site and hand work to each other through vaults, and the deployment docs vault was written by two of them.
  • The connector has a home. Claude's MCP connector reaches remote MCP servers from the API, Claude apps support custom remote connectors, and the Connectors Directory takes remote MCP servers, MCP Apps and plugins.
  • Skills already exist. skills.sgit.ai publishes eight skills, three of them for working with vaults: using sgit, writing vault content, and building vault apps.
  • What we would like: a place in the Claude Partner Network, a review of the connector, and support through Claude for Startups.

Where we are with Anthropic today

Anthropic's tools are how this site is made, so this is the partnership closest to what we already do. There is no relationship beyond being a customer. RiskMandate.ai has published agent behaviour policies for Claude Code on the web and on the command line, Claude Desktop, and Claude with Gmail and Microsoft 365, and the risk side of this partnership will be written there.

What a partnership could be

What we are asking Anthropic for

  1. A place in the Claude Partner Network.
  2. A review of the vault connector and the skills plugin before submission to the Connectors Directory.
  3. Support through Claude for Startups.
  4. A conversation about the case study: a website and its vaults run by Claude Code sessions.

What this page does not claim

  • No endorsement. Anthropic has not endorsed sgit, and we have not spoken to anyone there about this. Product and programme descriptions quote Anthropic's own pages and documentation as of 24 September 2026.
  • The vault connector does not exist yet. This page describes what it would be and which rules it would have to meet.
  • Being a heavy user is not a relationship. It is the reason for this page.

sgit.ai

sgit is git for encrypted vaults, clone, commit, branch and merge files that are encrypted with AES-256-GCM before they leave your machine. Open source, Apache-2.0, in beta and powering production workflows.

🔒 Thirty vaults on this site open in your browser with published read keys, every byte decrypted client-side, none of it readable by the server that stores it. The pages that describe them are ordinary static files. The medium is the message.
