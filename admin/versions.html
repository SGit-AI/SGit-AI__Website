Release history

This site ships by pushing its vault, and the site version — v0.1.10, shown in the nav of every page — increments on every push. Each release is also an sgit commit, so the vault's own sgit history log is the authoritative audit trail; this page is the human-readable index of it.

VersionDateVault commitChanges

Key hygiene: every example key on the site is now an obviously-invalid placeholder (format-valid example keys are squattable namespaces), enforced by a new validator rule.

sgit.ai

sgit is git for encrypted vaults — clone, commit, branch and merge files that are encrypted with AES-256-GCM before they leave your machine. Open source, Apache-2.0, in beta and powering production workflows.

🔒 This site is itself served from an encrypted SG/Send vault — the page you are reading was decrypted in your browser. The medium is the message.
