The architecture piece behind everything the newsroom shipped this week. Dinis's long-standing rule (no database: the file system is the database, LETS) gets its second step: no back end. The newsroom's personas, meter, payment on-ramp, private reading area and encrypted sharing all run in the browser, on commodity servers that cannot read the reader's data. It includes the architecture diagram, the accepted security gaps from SG Meter's model, and the release log (114 releases, 1 to 11 October). It belongs with the meter and persona articles, and in the site-and-engineering collection.
